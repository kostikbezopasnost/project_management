# Концепции проекта
Рассматриваются четыре концепции программного проекта.
| № | Концепция |
| :---: |:---: |
| А1 | Система управления командными задачами и рабочими процессами |
| А2 | Система персонального и семейного финансового учёта |
| А3 | Система онлайн-бронирования услуг и управления записями |
| А4 | Система планирования тренировок и отслеживания физической активности |


# Критерии оценки
| № | Критерий оценивания |
| :---: | :---: |
| K1 | Полезность проекта |
| K2 | Простота реализации |
| K3 | Интерес команды |
| K4 | Перспективность проекта |
