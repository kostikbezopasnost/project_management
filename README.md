## Навигация по репозиторию

| Фаза | Название |Каталог | Содержание |
| :---: | :---: | :---: | :---: |
| 1 | Выбор концепции | `phase_1/` |  Как минимум 4 идеи проекта и 4 критерия их оценки. Экспертные трёхточечные оценки (пессимистичная, ожидаемая, оптимистичная). Отбор лучшего варианта через нечёткий коллективный TOPSIS и чёткий коллективный МАИ. Сопоставление полученных результатов. |
| 2 | Распределение работы | `phase_2/` | Разбиение работ третьей фазы на задачи. Экспертная оценка их сложности. Личные предпочтения участников по задачам. Формулировка и решение задачи распределения. |
| 3 | Оценка проекта | `phase_3/` | Не менее 10 Use Cases. Оценка в COSMIC FP и Use Case Points. Коллективная экспертная оценка трудозатрат. Выводы о масштабе, составе команды и сроках. |
| 4 | Прогнозирование | `phase_4/` | Разбиение работ пятой фазы на задачи. Трёхточечные оценки времени. Две модели Монте-Карло: по числу задач за неделю и по недельным трудозатратам. Срок выполнения с 80% достоверностью. |
| 5 | Планирование | `phase_5/` | 20–25 задач проекта. Состав команды как типы ресурсов. Ресурсные требования и связи предшествования. Перебор эвристик упорядочения. Календарный план на 40-часовую неделю. |
| 6 | Итоговый отчёт | `report/` | Сводка по всем фазам: как выполнялись работы, промежуточные и конечные результаты. Актуальная матрица RACI с обоснованием распределения задач. Ссылка на публичный таск-трекер или доступ для преподавателя. Ссылка на облако или репозиторий с материалами. |
