## Постановка задачи распределения

Для каждой задачи третьей фазы нужно выбрать одного ответственного из трёх участников команды. Трудозатраты и индивидуальные баллы предпочтения берём из [таблицы оценок](predpochteniya%20uchastnikov.xlsx). Балл 1 соответствует непрофильной задаче, балл 5 — профильной. Предварительную оценку времени для каждой задачи считаем одинаковой для всех исполнителей.

Пусть $i$ — номер задачи, а $j$ — участник команды. Обозначим через $t_i$ трудозатраты задачи в часах, через $p_{ij}$ — балл, который участник $j$ поставил задаче $i$, и через $x_{ij}$ — переменную назначения. Значение $x_{ij}=1$ означает, что участник $j$ отвечает за задачу $i$.

Ограничение гарантирует, что у каждой задачи ровно один ответственный.

$$
x_{ij} \in \{0,1\}, \qquad \sum_j x_{ij} = 1 \quad \text{для каждой задачи } i.
$$

Сначала максимизируем сумму баллов по выбранным назначениям.

$$
P(x) = \sum_i \sum_j p_{ij} x_{ij} \longrightarrow \max.
$$

Затем фиксируем максимальное значение $P^*$ и среди назначений с $P(x)=P^*$ минимизируем нагрузку самого загруженного участника. Для этого вводим верхнюю границу нагрузки $L$ и минимизируем её.

$$
\sum_i t_i x_{ij} \le L \quad \text{для каждого участника } j, \qquad L \longrightarrow \min.
$$

Такой порядок позволяет отдавать задачи участникам с более высокими оценками предпочтения и выравнивать нагрузку там, где это можно сделать без потери баллов. Предел часов на участника не задан, поэтому нагрузка выступает вторым критерием. Постановка опирается на задачу о назначениях из лекции «Автоматизация в проектном менеджменте» (слайд 9) и критерий выравнивания загрузки из лекции «Автоматизация планирования» (слайд 20).

## Решение

[Скрипт на Python](solve_assignment.py) читает оценки из Excel и перебирает все $3^7 = 2187$ вариантов. Каждый вариант сравнивается сначала по сумме предпочтений, затем по максимальной нагрузке. Полный перебор гарантирует оптимальность, поскольку включает каждое назначение, удовлетворяющее ограничению.

| № | Ответственный | Трудозатраты, ч | Балл предпочтения |
| :---: | :--- | ---: | ---: |
| 1 | Андрей | 4 | 5 |
| 2 | Андрей | 5 | 4 |
| 3 | Константин | 6 | 5 |
| 4 | Константин | 5 | 5 |
| 5 | Олег | 3 | 5 |
| 6 | Олег | 2 | 4 |
| 7 | Олег | 4 | 5 |
| **Итого** | | **29** | **33** |

Нагрузка Андрея составляет **9 ч**, Константина — **11 ч**, Олега — **9 ч**. Все задачи получили максимальный доступный для них балл. У каждой задачи такой балл выставил только один участник, поэтому оптимальное назначение единственно уже по первому критерию. Максимальная нагрузка в этом назначении составляет **11 ч**.
